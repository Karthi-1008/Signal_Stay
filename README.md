# Signal_Stay
Customer Churn Prediction for a Telecom Company based ML model


a telecom company loses money when customers leave. Keeping an existing customer is much cheaper than finding a new one. If we can predict who will leave, the retention team can contact them early with offers.

Define the target: Churned = 1, Stayed = 0 (Joined customers are removed, see the dataset section).

problem, target, data source, success measures.
